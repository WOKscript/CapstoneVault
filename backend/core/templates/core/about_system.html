What is CapstoneVault?

CapstoneVault is a web-based repository designed to store, organize, and manage capstone papers in one place. It helps users find relevant studies faster through smart categorization, role-based access, and trend analytics— making the IT e-library more accessible, secure, and useful for future researchers.

Faster Discovery

Search and filter by category, subcategory, year, and keywords to locate papers quickly.

Controlled Access

Role-based access and request-to-view mechanisms help protect documents and reduce misuse.

Intelligent Classification

Papers can be auto-categorized (e.g., using TF-IDF + SVM) to reduce manual sorting.

Research Insights

Analytics highlight popular topics and trends to guide future capstone directions.

How it works (quick flow)
Upload & Review

Uploaded papers go through a review/approval flow (Admin/Adviser) before appearing in the repository.

Categorize & Tag

The system assigns categories/tags to improve searching and reduce manual classification.

Request-to-View

Some users may need to submit a request before viewing full PDFs to protect documents.

Trends Dashboard

Trends summarize what topics are rising by year and category for better decision-making.

User Roles
Admin
Manages users, approvals, logs, requests, and system modules.
Adviser / Instructor
Reviews submissions, approves papers, and manages upload access for verified users.
Verified User
Can browse papers and may upload depending on adviser-granted permission.
Non-Verified User
Typically limited to abstracts and must request access to view full papers.
Privacy & Security Note

CapstoneVault supports access control and review workflows to help prevent loss, misuse, and unmanaged distribution of academic documents.
